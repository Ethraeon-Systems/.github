# Contributing

ETHRAEON Systems is a sovereign engineering estate. Internal source code is developed under CEO sovereign authority (S. Jason Prohaska) and is not open to external contribution at this date.

## What is open

- Bug reports and security disclosures on public repositories (see SECURITY.md).
- Discussion and questions in public repository issues where enabled.
- Public documentation typo and clarification suggestions via issue.

## What is not open

- External pull requests against internal engineering repositories.
- External modification of the constitutional runtime, evidence chain, or patent-adjacent source.
- Grants of contributor rights are made by CEO sovereign act only.

## How to engage

- File an issue on the affected public repository.
- For security matters, follow SECURITY.md.
- For commercial or research inquiry, contact jason@ethraeon.systems.

## Attribution

All external contributions accepted under this policy require agreement to the ETHRAEON Systems contributor terms (attached to the accepting pull request or discussion at the moment of acceptance). No prior contributor license agreement is required to file an issue.
